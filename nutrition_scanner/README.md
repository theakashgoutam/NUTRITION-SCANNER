# NUTRITION SCANNER
### Premium AI Food Nutrition Scanner & Health-Tech Web Application

A consumer health-tech AI application built specifically for hackathons and college students using **Python + Streamlit**.

---

## 🌟 Visual Identity & Key Highlights

- **3D Fruit Basket & Energy Blast**: Featuring levitating fruits (🍎 Apple, 🍊 Orange, 🍌 Banana, 🍓 Strawberry, 🍇 Grapes, 🥝 Kiwi, 🍍 Pineapple) crafted with hardware-accelerated CSS3 3D transforms, lighting, and particle trails embedded directly into Streamlit.
- **Documented Streamlit Limitation**: Outlines how server-side Streamlit execution is reconciled with advanced front-end visual effects.
- **Glassmorphism & Soft 3D**: Fresh fruit-inspired color system (Apple green, Lime, Mango yellow, Strawberry red, Berry purple) with translucent cards, soft blurs, and responsive padding.
- **Multi-Food Perception**: Accurately detects composite meals (e.g. Rice, Dal, Paneer, Salad, Roti) and allows students to review, adjust portion sizes, and calibrate uncertainty.
- **Student Mode & Budget Optimizer**: Target goal switching (💪 Muscle Gain, 🔥 Fat Loss, ⚖️ Maintain Weight, 🥗 Healthy Eating, 💰 Budget Eating) with realistic hostel swaps and cost comparisons.
- **Weekly Insights**: Plotly charts visualizing daily calorie balance, protein trends, and health scores.

## 🚀 Quick Start Instructions

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **(Optional) Set Gemini API Key for Live Vision:**
   ```bash
   export GEMINI_API_KEY="your-gemini-api-key"
   ```

3. **Run the Application:**
   ```bash
   streamlit run app.py
   ```
